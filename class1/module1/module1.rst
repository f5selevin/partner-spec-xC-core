Publish the application
#######################

In this section, you will publish an existing internet-facing Arcadia Crypto application through the F5 Distributed Cloud Global Network. You will create three origin pools, attach them to an HTTP load balancer, and verify round-robin traffic distribution by observing the origin pool name in the application's header and footer.

The application domain for these exercises is ``$$namespace$$.spec-core.f5se.com``.
