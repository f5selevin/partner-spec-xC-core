Malicious User Detection
########################

F5 Distributed Cloud Malicious User Detection identifies and tracks users across sessions by using signals such as client IP addresses, TLS fingerprints, cookie values, and HTTP header values. Malicious User Mitigation and Challenges can then block or challenge users based on their observed behavior.

In this module, you will configure Malicious User Detection on the HTTP Load Balancer by using the **Authorization** header and client IP address as user identifiers. You will generate malicious authenticated and unauthenticated traffic, review detected users in the Security dashboard, and add a blocked IP address to the allow list.
